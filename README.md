# 2026年国庆行程规划

本项目为两位成人、福州鼓楼区往返的四天三晚休闲旅行网页。

## 内容

- 千岛湖：铁路往返，游湖与酒店休闲；泰宁：自驾主线、动车备选；漳州：古城一晚、东山两晚。
- 10月2—5日与3—6日切换会同步更新逐日日期、酒店入住区间和铁路预计开售日。
- 七家酒店已在登录后的携程页面按两组日期检查。六家读到大床报价，闽江饭店两组均显示暂不接受预订。
- 连住报价是平均每晚价，不能保证每一晚都低于1200元；页面显著说明。报价可能含会员优惠、随时变化，没有下单或锁价。
- 景点每组3张实景，酒店每组2张客房内景、2张外观。只有明确标注“对应报价房型”的照片确认到具体大床房，其余仅供了解酒店内景，房型、楼栋和朝向未核实。
- 上午、下午、晚上分别勾选，去返程与必要转场固定；两组日期分别记忆，可恢复默认推荐。默认最多2个休息半天，每地2晚饭后轻活动。
- 地图链接搜索对应地点并尝试打开高德；需核对入口后选择驾车路线。公里数仍为参考或估算。

## 文件

- `app/page.tsx`：页面和交互；`app/globals.css`：响应式样式。
- `app/travel-data.ts`：行程、景点、交通、来源与预算。
- `app/hotel-rates.ts`：按日期核实的酒店报价、早餐与取消条件。
- `public/images/`：实景图片；来源见页面及研究记录。
- `research/`：保留精简核查证据，不公开发布；临时下载和制作文件在交付后清理。
- `github/`及`vite.github.config.ts`：GitHub Pages入口，与Sites共用同一页面、样式和数据。
- `.openai/hosting.json`：Sites关联信息，不含凭证。

## 运行

使用Node.js 22.13以上版本。在此文件夹中运行 `npm install`，之后用 `npm run dev` 预览，或 `npm run build` 构建。

## 核查范围

报价核查日期2026-08-30，图片与景点补充2026-08-31。铁路为近期参考时刻，国庆票尚未开售；起售日按15天预售期推算。驾驶里程、车程、出租车和餐饮费用为规划估算。国庆景区班次、道路限制、停航情况和天气须在出发前再次检查。2026-08-31已登录飞猪核查闽江饭店：两组日期、1间2成人均显示暂时没有可售房型；未取得报价和套餐退改，不推断售罄原因。

不收集旅行者信息，无登录、支付、自动订票功能。勾选清单只保存在访问者自己的浏览器。公开站点只显示福州鼓楼区，不包含精确出发地址。
