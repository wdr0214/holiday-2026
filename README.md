# 2026年国庆行程规划

福州鼓楼区往返，2成人、1间大床，2026年10月2—5日或3—6日。

- 千岛湖2晚＋歙县1晚：湖区游船、徽州古城与渔梁古镇。歙县为返程方向停点，用两个半天游览；单晚限600元，其余每晚限1200元。
- 泰宁3晚：大金湖、九龙潭、古城；自驾与铁路备选。
- 漳州2晚＋东山1晚：古城、南靖田螺坑线路、南门湾与风动石。
- 梅州3晚：客家博物馆、东山书院、千佛塔寺、嘉应古城、磐安围、五华热矿泥温泉。
- 丽水3晚：古堰画乡连住，云和梯田与缙云仙都各安排完整一天；画廊30—45分钟，返程日上午看古堰。

按上午、下午、晚上勾选，说明默认折叠。必要交通固定，完整景区日游联动。交通预计超过5小时减少额外休息时段，保留驾驶安全休息。交通仅在对应行程下方展示。
